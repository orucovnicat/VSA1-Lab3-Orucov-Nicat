# Laboratoriya işi 3

Bu tapşırıqda **bağlı siyahı (linked list)** əsasında növbə strukturları yaradılır.

---

### Məsələ 1. Aptek növbəsi
* Müştərilər ad və dərman adı ilə növbəyə əlavə olunur.
* Yeni müştəri növbənin sonuna daxil edilir.
* İlk gələn müştəriyə əvvəl xidmət göstərilir (**FIFO** prinsipi).

---

### Məsələ 2. Avtobus növbəsi
* Sərnişinlər yaşlarına görə iki növbəyə ayrılır.
* Yaşı 65-dən böyük olanlar **prioritetli növbəyə** daxil edilir.
* Avtobus gəldikdə əvvəlcə prioritetli növbəyə xidmət edilir, o boşaldıqda isə adi növbədən sərnişin qəbul olunur.

---
